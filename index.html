Technical report

A 19-page technical report covering the learning engine's equations, how the site is built, and a reproducible evaluation: a gradient check, benchmarks of every mission, model-capacity, overfitting and learning-rate experiments. Every number in it is produced by a script that runs this site's own code, and complete training runs are independently reproduced in JAX/Optax to machine precision (largest difference 7×10⁻¹⁵); with no hidden layer the network converges to the exact logistic-regression MLE and least-squares solution.

Inspiration

Academic origin

This project was inspired by EN.553.413/613 Applied Statistics and Data Analysis (ASDA), taught by Prof. Suryanarayana Maddu in the Department of Applied Mathematics and Statistics at Johns Hopkins University (Fall 2026). The course's treatment of maximum likelihood, logistic regression, ridge and lasso regularisation, the bias–variance trade-off and model selection shaped the Academy's lessons and the training missions. Here a sigmoid neuron is logistic regression, log loss is a negative log-likelihood, and weight decay is ridge.

The interactive format was also inspired by TensorFlow Playground. All code on this site is written from scratch.

Training missions

Each one loads a setup and a question. They go from "why does this fail?" to "can you beat the spiral?". Each teaches one idea you'll meet in any machine learning course.

Under the hood

Everything here runs in your browser with a hand-written network, about 200 lines of JavaScript and no libraries.

Forward pass

Each neuron is a weighted sum plus a squash

A neuron computes a = f(w·x + b). The first hidden layer can only draw straight lines. Each later layer combines those lines into curves, rings and spirals.

Loss

Classification uses log loss

The output neuron is a sigmoid, so it is literally logistic regression on the last hidden layer. Training minimises the negative log-likelihood. Regression uses squared error.

Backpropagation

The chain rule, layer by layer

For every example the error at the output, p − y, flows backwards. Each weight's gradient is (error arriving at its neuron) × (input it saw). Step through it →

Update

Gradient descent on mini-batches

After each batch, every weight moves a step −η × gradient. One epoch is one pass through the training data. Momentum and Adam are smarter ways to choose that step.

Regularization

L2 = ridge, L1 = lasso

L2 adds λw to each gradient (weight decay), shrinking weights smoothly. L1 adds λ·sign(w), pushing weak weights to exactly zero, so the lines vanish.
