Training missions

Each one loads a setup and a question. They go from "why does this fail?" to "can you beat the spiral?". Each teaches one idea you'll meet in any machine learning course.

Under the hood

Everything here runs in your browser with a hand-written network, about 200 lines of JavaScript and no libraries.

Forward pass

Each neuron is a weighted sum plus a squash

A neuron computes a = f(w·x + b). The first hidden layer can only draw straight lines. Each later layer combines those lines into curves, rings and spirals.

Loss

Classification uses log loss

The output neuron is a sigmoid, so it is literally logistic regression on the last hidden layer. Training minimises the negative log-likelihood. Regression uses squared error.

Backpropagation

The chain rule, layer by layer

For every example the error at the output, p − y, flows backwards. Each weight's gradient is (error arriving at its neuron) × (input it saw). Step through it →

Update

Gradient descent on mini-batches

After each batch, every weight moves a step −η × gradient. One epoch is one pass through the training data. Momentum and Adam are smarter ways to choose that step.

Regularization

L2 = ridge, L1 = lasso

L2 adds λw to each gradient (weight decay), shrinking weights smoothly. L1 adds λ·sign(w), pushing weak weights to exactly zero, so the lines vanish.
