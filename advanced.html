Advanced 01

Softmax: from two classes to many

A sigmoid gives one probability. Softmax gives a whole distribution over any number of classes.

The Console's output neuron answers a yes/no question. For K classes, the network produces K scores called logits, and softmax turns them into probabilities that are positive and sum to one. Training minimises the cross-entropy −log ptrue, the negative log-likelihood of a multinomial model, so this is multinomial logistic regression on the last hidden layer.

p_k = exp(z_k / T) / Σ_j exp(z_j / T) ∂L/∂z_k = p_k − y_k

Lower the temperature and the distribution sharpens toward the largest logit (T → 0 is arg-max). Raise it and the distribution flattens toward uniform. This is the same "temperature" setting used when a language model picks its next word.

Connection to statisticsWith K = 2, softmax reduces exactly to the sigmoid: p = 1 / (1 + e−(z₁ − z₂)). The gradient p − y is the same "prediction minus target" as in logistic regression and least squares.
Advanced 02

Going deep: vanishing gradients, initialization and skip connections

Backpropagation multiplies one factor per layer. Thirty factors a little below one give almost nothing; a little above one, an explosion.

The figure builds a network of the depth you choose (32 neurons per layer), sends random inputs forward and a random error backward, and plots the size of the signal and of the gradient at every layer on a log scale. A healthy network keeps both lines roughly flat.

  • Sigmoid's slope is at most 0.25, so its gradient shrinks at every layer whatever the initialization. This is the vanishing gradient.
  • Xavier initialization (variance 1/n) keeps tanh networks stable; He initialization (2/n) does the same for ReLU, which zeroes half its inputs.
  • Skip connections (al = al−1 + f(W al−1)) add an identity path, so the gradient always has a route back that is not multiplied by small numbers. This idea, from ResNet, is what made networks with hundreds of layers trainable.
Advanced 03

Dropout: training a different network every step

Randomly switching neurons off during training stops any one of them from memorising the data.

At every training step each hidden neuron is kept with probability 1 − p and otherwise set to zero; the kept ones are scaled by 1/(1 − p) so the expected signal is unchanged. At test time all neurons are used. The effect is like averaging a large ensemble of thinned networks, and it lowers variance much as ridge does. Common trap"Dropout is also applied when making predictions." False. It is a training-time device. At test time every neuron is active; the 1/(1 − p) scaling during training is what keeps the two consistent.
Advanced 04

Convolution: one small detector, slid everywhere

Images have structure a fully connected layer ignores: nearby pixels belong together, and a cat is a cat wherever it sits.

A convolutional layer slides one small kernel of weights across the image and records how strongly each patch matches it, giving a feature map. The same nine weights are reused at every position (weight sharing). A ReLU keeps the positive matches, and max-pooling keeps the strongest response in each 2 × 2 block. Draw on the input, pick or edit a kernel, and hover the feature map to see the patch each value came from.

A dense layer from this 12 × 12 image to a 10 × 10 output would need 144 × 100 = 14,400 weights. The convolution needs 9. Fewer parameters means lower variance, and the same detector working at every position builds in the knowledge that location should not matter. A CNN stacks many such layers: early kernels find edges, later ones combine them into textures, parts and objects.

Advanced 05

Recurrent networks: memory, and why it fades

For sequences, a recurrent network keeps a hidden state and updates it at every step with the same weights.

The simplest recurrent unit is ht = tanh(w·ht−1 + u·xt). Below, the input is a single pulse at the first step and nothing afterwards, so the black curve shows how long the unit remembers it. The red curve is the influence ∂hT/∂ht: how much the final state would change if the state at step t changed. Backpropagation through time multiplies one factor w·(1 − h²) per step, so this is the vanishing-gradient problem again, along time instead of depth.

  • With w < 1 the memory decays and the influence of early steps vanishes: the unit cannot learn long-range patterns.
  • With w > 1 the state latches near ±1, where tanh is flat, so the gradient still vanishes; in a network without the squashing it would explode.
  • Lower the gate g: the update becomes ht = (1 − g)·ht−1 + g·(new value), so most of the old state is carried forward unchanged and the influence stays near (1 − g)T instead of collapsing. Learned gates of this kind are the idea behind LSTM and GRU units.
Advanced 06

Attention: letting every word look at every other word

Instead of squeezing a sentence through one fading memory, attention lets each position read directly from all the others.

Each word is a vector. To update a word, scaled dot-product attention scores it against every word (a dot product, large when two vectors point the same way), turns the scores into weights with a softmax, and takes the weighted average of the other vectors. Click a word to make it the query.

weights_i = softmax( β · e_i · e_j / √d ) output_i = Σ_j weights_ij · e_j
sharpness β
Attention matrix (row = query, column = word attended to)

The word vectors here are a hand-made toy with four features (living thing, place or object, action, grammar word), chosen so related words point the same way. A real transformer learns its vectors, and learns separate query, key and value projections for many attention "heads".

Look at "it": apart from itself, its strongest links are to "cat" and "tired", which is how a model can work out what a pronoun refers to. Switch on the causal mask and each word can only look backwards. That is the rule in GPT-style models, which predict the next word from the words so far. Because no step depends on a long chain of earlier steps, the gradient path between any two words has length one, which removes the fading-memory problem of the previous module.

Overview

From this lab to modern AI

Every architecture below is trained the way the Console trains its small network: a forward pass, a loss, backpropagation, and gradient descent. What changes is the structure built into the layers.

Multilayer perceptronFully connected layers. No assumptions about the input. The Console's network. Good for tabular data.
Convolutional network (CNN)Shared local detectors plus pooling. Assumes nearby inputs matter together and position should not. Images, audio, grids.
Recurrent network (RNN, LSTM, GRU)One cell reused at every time step with a carried state. Assumes order matters. Sequences; long memory needs gates.
Residual network (ResNet)Skip connections around blocks so gradients survive hundreds of layers. Used inside almost every modern model.
TransformerStacks of attention and small perceptrons, with skip connections and normalization. Every position reads every other directly. Language models, and increasingly images and science.
RegularizersL2 weight decay, dropout, early stopping, data augmentation. All trade a little bias for less variance.
