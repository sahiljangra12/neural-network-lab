Module 01

The neuron: a weighted vote and a squash

Every neural network, from this page to the largest language models, is built from one simple unit.

A neuron takes its inputs, multiplies each by a weight, adds a bias, and passes the total through an activation function:

a = f( w₁x₁ + w₂x₂ + b ) = f(z)

The weights decide which inputs matter and in which direction. The bias shifts the threshold. The weighted sum z is zero along a straight line, so one neuron always splits the plane with a straight line. The activation decides how sharply it switches from one side to the other.

w₂
bias b

The dashed line is the decision boundary where z = 0. Change w₁ and w₂ to rotate it; change b to slide it. Larger weights make the switch sharper. Hover the map to probe a point.

Connection to statisticsWith a sigmoid activation, one neuron is logistic regression: P(y = 1) = σ(wᵀx + b), and the log-odds wᵀx + b are linear in x. Training it by minimising log loss is exactly maximum likelihood.
Module 02

Activation functions: where the bending comes from

Without a nonlinear activation, a hundred layers can do no more than one.

The activation is applied to each neuron's sum. Its shape sets what the neuron can express, and its slope (derivative) sets how well a learning signal can pass back through it during training.

f(z)slope f′(z)

Common trap"Neural networks must never use linear activations." False. A linear output layer is standard for regression. What fails is a network that is linear everywhere: W₂(W₁x + b₁) + b₂ = (W₂W₁)x + c collapses into a single linear model.
Module 03

Why hidden layers: combining lines into shapes

One neuron draws a line. A layer of neurons draws several lines. The next layer combines them.

Below, three networks train on the same data at once. The first has no hidden layer, so it is plain logistic regression. The second has 4 tanh neurons. The third also has 4 hidden neurons, but they are linear.

Only the nonlinear hidden layer can bend the boundary. This is the universal approximation idea: with enough hidden neurons and a nonlinear activation, a network can approximate any smooth function. Depth helps further: each layer can fold the space the layer before it built, so deep networks express complicated shapes with far fewer neurons.

Hidden layers as learned featuresAdding X₁² or X₁X₂ by hand (basis expansion) also lets a linear model bend. A hidden layer learns its own features from the data instead. Compare both in the playground →
Module 04

Loss: putting a number on "wrong"

Training needs one number to push down. That number is the loss.

Classification: log loss

The true label is y = 1. Drag the predicted probability p and watch the penalty.

p

Regression: squared error

The true value is y = 0. Drag the prediction ŷ.

ŷ

Log loss punishes confident mistakes without limit: predicting p = 0.01 for something that happened costs −log(0.01) ≈ 4.6. Minimising the average log loss is the same as maximising the likelihood of the labels under a Bernoulli model. Squared error is the Gaussian-likelihood equivalent, the same criterion OLS minimises.

Module 05

Gradient descent: walking downhill blindfolded

A network has no formula like (XᵀX)⁻¹Xᵀy for its best weights, so it searches step by step.

At the current weights, compute the gradient ∇L, the direction of steepest uphill, and step the other way: w ← w − η·∇L(w). The learning rate η is the step size. Click anywhere on the map to drop a starting point.

η
noise

What to tryOn the narrow valley, plain gradient descent zig-zags across and crawls along the floor. That is what happens with unscaled, correlated inputs (large condition number κ), and it's why we standardize. Momentum builds speed along the floor. On two minima, where you start decides where you end; adding noise can sometimes jump the ridge.
Module 06

Backpropagation, one number at a time

Gradient descent needs ∂L/∂w for every weight. Backprop gets all of them in one backward sweep using the chain rule.

Here is a tiny network: 2 inputs, 2 tanh hidden neurons, 1 sigmoid output, with log loss. Step through one full training update. Every number is computed live, so you can change the inputs and target.

The pattern to rememberFor every weight: gradient = (error δ arriving at the neuron it feeds) × (the input it carried). The error at a hidden neuron is the output error, weighted by the connection and scaled by the activation's slope: δⱼ = δₒ · wⱼ · f′(zⱼ). If those slopes are small (sigmoid's is at most 0.25) and you multiply many of them, gradients vanish.
Module 07

Overfitting and regularization

A big enough network can memorise its training data, noise included. The test set catches it.

Two identical networks (2 hidden layers of 8 neurons) train on the same 50 noisy points. The right-hand one has an L2 penalty ½λ‖w‖² added to its loss (its gradient is λw). That is ridge regression's penalty, called weight decay in deep learning. Watch the test loss.

No regularization
With L2 (weight decay)
No reg · testNo reg · trainL2 · testL2 · train
  • Bias–variance: more neurons and layers lower bias but raise variance. Unregularized, the train loss keeps falling while the test loss turns back up.
  • L2 (ridge) shrinks all weights smoothly, giving a smoother boundary and lower variance at the cost of a little bias.
  • L1 (lasso) drives weak weights to exactly zero, which removes connections.
  • Early stopping halts when validation loss is lowest. It acts like regularization.
  • Choose λ, the size of the network and the learning rate with validation data / cross-validation, never with training loss.
